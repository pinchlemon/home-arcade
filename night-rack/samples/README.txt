Night Rack drum samples. Each folder keeps its original note.
tr909/   Roland TR-909 set by Jason Baker / Rob Roy Recordings (1995). Complete and unmodified, free to copy or distribute, not for profit (see TR909SET.TXT).
tr808/   Roland TR-808 set by Michael Fischer / Technopolis (1994), released free with no restrictions (see TR808.TXT). Selected files, unmodified.
tr707/   Roland TR-707 set by Francois Dion, released with no restrictions (see README.txt). Selected files, unmodified.
samplepi/ Sample Pi (from Sonic Pi's sounds), CC0 1.0 public domain. Via github.com/danigb/samples.
