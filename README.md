# home-arcade

## Hedron app (`app/`)

Hedron (the repo is still called home-arcade, so the web address is unchanged): play every game with a controller, and make small games on the phone with the touchscreen. Open https://pinchlemon.github.io/home-arcade/app/ in Safari and use Add to Home Screen. It works offline.

- **Arcade**: every game in this repo. The game you select here is the one the Studio, Art and Sound tabs work on (marked Editing). D-pad picks, A plays, X edits.
- **Studio**: the selected game and its parts (Change game goes back to the Arcade). Edit opens the game editor: Scene (with a Backdrop view of the background layers), Objects (reusable templates and their behaviors) and Settings.
- **Art**: the current game's pictures in folders (sprites, props, backdrop) and the pixel symbols its objects use. View them big; sprite sheets play their animations. **Draw** opens the sprite editor (Aseprite-style: pencil, eraser, fill, colour picker, palette, layers, frames, onion skin, tags, playback, undo; pinch to zoom, two-finger tap to undo; select by box, lasso or magic wand, move, copy/cut/paste, flip, turn and scale; canvas size, trim, crop, scale and turn the whole sprite; import a picture or an .aseprite file; export PNG, sprite sheet, animated GIF or .aseprite through the share sheet). A new sprite can also start from a file. **+** adds a new sprite to a folder. Drawings are kept on the phone as an `.aseprite` file plus the `.png` the game reads, show up in the game straight away, and go to GitHub from Sync (new sprites are added to `studio.json`).
  - **Tool bar**: icons only; the chosen tool has a round ring (its name is kept hidden, so holding it can still rename it).
  - **Shapes** tool: drag from corner to corner for a line, box, filled box, oval or filled oval (the shape button in the colour bar cycles them). The shape redraws as the finger moves and is one undo step.
  - **Colour tools** (sprite editor): Shade tool steps pixels one colour darker or lighter along the palette (DARK/LIGHT switch in the colour bar; a ramp is a run of neighbouring palette colours of the same hue family). Palette button opens the palette sheet: choose a colour, Edit colour (with "Recolour the sprite" it replaces every pixel of the old colour, in every frame), Make ramp (5 shades with hue shift), move, sort by light, add colours from the sprite, remove unused, import (.hex, .gpl, .pal, .aseprite, PNG/GIF), export (.hex, 1-pixel .png), presets (PICO-8, Sweetie 16, Game Boy, Hedron).
- **Sound**: the current game's sound effects and music, played by the game's own sound code (`engine/listen.html`).
- **Settings**: controller, Sync (push your changes to GitHub; the tab shows a dot when there is something to push), GitHub token, audio, display.
- **Icons**: hold any pixel icon (on a button, a row or a greyed-out button; the sprite editor's too) for half a second to redraw that one button only (kept per screen + icon + button label in `ha.icons.slots`; `applySlots` in `iconEditor.js` lays it on whenever the screen is drawn). Editing from the list (Edit) changes the icon everywhere it is used. When editing one button, the "Update list icon" switch also saves the picture to the icon it came from (on by default when you picked that icon from the list), which changes it on every button using it; off keeps it to this button. The editor has: draw, slide all pixels left/up/down/right (they wrap around), resize 3 to 12 pixels, undo, back to the original. The list button shows every icon; select one to see its name and where it is used, then Use here (copy its picture in), Edit, Rename, or Delete (only icons you made). + makes a new icon. Everything is kept on this phone (`ha.icons` redrawn, `ha.icons.mine` made, `ha.icons.names`, `ha.icons.seen`), not pushed to GitHub. "Used on" comes from `USED_ON` in `pixel.js` (found by tapping through every screen; rebuild it when screens change) plus the screens this phone has shown each icon on. Controller: D-pad moves, A flips a pixel (in the list: uses that icon here), X saves, B cancels.
- **Button text**: holding a button also lets you change its name and description (the text button in the editor's top bar). Holding a settings row, or any button without an icon, opens just the text. Kept per screen + the button's original name in `ha.text.slots`; "Original text" puts it back. Leave a description blank for none: the name then sits in the middle of the button (an empty description is hidden).
- **Moving buttons**: in the hold editor, Move (then tap another button in the same group) swaps two buttons. A group is the buttons sharing one parent on one screen. Orders are kept on this phone (`ha.order`, `arrange.js`) and applied whenever the screen is drawn; Original order in the Move bar puts a group back.
- **Customizations on GitHub**: icons, button text and button order (the hold editor's changes) show in Settings › Sync as "App customizations". Push sends them to `app/custom.json`; a phone or browser with none of its own (new phone, cleared Safari data, a test browser) starts from that file (`app/js/custom.js`, loaded before `pixel.js`). The review screen also has Export / Import (a .json file) and Discard (back to GitHub's).
- **New game** (Arcade › New game): makes a game on the tile engine from a template, Platformer or Top-down (`app/js/newGame.js`). Its files (`index.html`, `game.json`, `studio.json`) live in `games/<name>/` in the phone's IndexedDB and `sw.js` serves them from there, so it plays offline before it is pushed. Sync pushes them and adds the game to `games/index.json`, which every phone reads to list it. The runtime is `engine/tiles.js` (8×8 tiles that are solid, platforms, hurt or decor; objects mixing behaviors; player with jump or 4-way movement, shooting, stomping, hearts; exit to the next scene); the page comes from `engine/game-template.html`.
- **Tile scene editor** (Studio › Scene, for tile games; `app/js/screens/tileScene.js`): Paint, Box, Erase tiles; Place objects, the player start and the exit; Select to drag or nudge a thing; Hand; two fingers pan and pinch-zoom. The level shows a **Plan** view by default (black background, each tile a one-colour 8×8 plan symbol, same size as in the game); the PLAN/GAME button swaps to the game art. Each tile has a plan symbol (its own, or the shape of its game art) and a plan colour (`plan`, `planColor` in game.json; the engine ignores them). Tiles are drawn in the tile editor (`app/js/tileEditor.js`, Game art and Plan tabs: Colour/Shade/Clear inks, colours, kind, slide, flip, fill, duplicate, delete, a 3×3 preview), opened from the level editor's pencil or from Art › Tiles, which lists every tile. Scenes can be added, duplicated, renamed, deleted and resized. Each stroke or drag is one undo step.
- **Visual logic** (Studio › Logic, for tile games; `app/js/screens/logicGraph.js`): a node graph. Boxes sit on a canvas and wires join their dots: white wires carry the flow (what runs next), blue wires carry a number into a box's setting. Events start a chain (scene starts, on a timer, player touches or collects a thing, thing defeated, none left, touches a tile, button pressed, player hurt, out of hearts, signal received); Flow boxes choose, wait and repeat (If, Wait, Repeat, Only once, Chance); Actions do things (score, hearts, your own numbers, make or remove things, swap or put tiles, move or push the player, player settings, show text, play a sound, go to a scene, finish the scene, send a signal); Values give numbers (your numbers, score, hearts, how many, player position, time, random, math). Touch: drag the background to move, two fingers to zoom, drag a box to move it, tap it to change its settings, drag from a dot to another dot (or tap one, then the other) to join them, tap a wire to cut it; + BOX lists the boxes (only the ones that fit when a dot is picked, and the new box arrives joined). A game can have several graphs, each running in one scene or all of them. The boxes are listed in `engine/logic.json`; `engine/logic.js` runs the graphs in the game (tile games made before this get it too, through `engine/boot.js`); a game keeps its graphs in `game.json` under `logic` (`[{ id, name, scene, nodes: [{ id, t, x, y, p }], wires: [[from, port, to, port]] }]`). Each change is one undo step. The canvas is touch only; the controller still reaches the panel's buttons.

Studio, Art and Sound share one game: the one selected in the Arcade. A game opens in them when it has a `game.json` and a `studio.json` (see `crab-platformer/`): `studio.json` says which settings the Studio shows and lists the game's art and sound. Changes made on the phone are kept as a list of changed settings and pushed onto `game.json`.
